# Пошаговая сборка теста Vitest

Скилл для создания каркаса и пошаговой сборки модульного теста без лишних запусков тестового раннера.

## Правила и ограничения

1. Запрещен полный прогон тестов. Запуск строго таргетированный (`npx vitest run <target.test.ts>`).
2. Все описания (`describe`, `it`, `test`) писать строго на русском языке.
3. TypeScript: соблюдать `erasableSyntaxOnly` (без enum и без parameter properties).

## Процесс работы

### Этап 1: Инициализация каркаса
При запросе создания теста для `<Класс|Модуль>`:
1. Определить или создать целевой файл `<target>.test.ts` рядом с тестируемым модулем.
2. Создать каркас:
   - Необходимые импорты (`describe`, `it`, `expect`, `vi`, `beforeEach`).
   - `beforeEach` с моками ядра (события, DOM/SVG окружение, менеджеры при необходимости).
   - Базовый блок `describe('<НазваниеКласса>', () => { ... })`.
   - Один пустой тестовый кейс `it('...', () => {})`.
3. Не запускать Vitest на этом этапе.

### Этап 2: Пошаговая сборка
1. Каждая последующая реплика пользователя переводится строго в строки теста (arrange-act-assert).
2. Минимальные точечные правки без переписывания файла.
3. Не запускать Vitest автоматически.

### Этап 3: Проверка
1. Запуск Vitest выполняется строго по команде `!проверь`:
   ```bash
   npx vitest run <target.test.ts>
   ```
2. При падении теста — устранить ошибку в тесте или коде и повторить целевой запуск.
