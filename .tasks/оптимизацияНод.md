- [ ] **3. Таргетированные подписки:** Избавиться от слушателя `EVENTS.node.updated` на каждом `VNode`.
- [ ] **4. Кеширование `getNodeRect()`:** Закешировать прямоугольник дерева с инвалидацией по флагу изменения.
- [x] **5. Изоляция Z-Index:** Перевести поднятие наверх `bringToFront` на CSS Stacking Context вместо цикла по всем нодам.
- [ ] **6. Быстрый обход `forEachChildren`:** Не клонировать и не сортировать массивы там, где порядок не важен.

- [ ] **11. Делегирование событий кнопок:** Единый обработчик на контейнере вместо сотен `addEventListener`.
- [ ] **12. Оптимизация `onInput`:** Исключить сброс ширины и рекурсивный сдвиг при наборе символов без изменения высоты.
