# План: Отмена действий (Undo / Redo)

## Контекст
- Клиент: `client/src/features/core/history.ts` (`History`), `interfaces.ts` (`Command`), `comands.ts` (Ctrl+Z / Ctrl+Shift+Z).
- Текущее состояние: реализована отмена только одиночного перетаскивания одной ноды (`VNode.ts`).

## Что необходимо реализовать

### 1. Архитектурные улучшения History
- `BatchCommand` / `CompositeCommand`: объединение набора команд в одну транзакцию (для групповых операций).
- Ограничение размера стека `past` (например, 50-100 записей) для предотвращения утечек памяти.
- Интеграция с сохранением на сервере при `undo()` / `redo()`.

### 2. Действия для отмены (по приоритету)
1. **Удаление / Восстановление нод**:
   - Одиночное удаление (`Delete`/`X`), удаление группы, удаление с клонами (`Shift+Delete`).
   - Метод `NodeManager.restoreNodeFromTrash(node)` для возврата из корзины.
2. **Создание / Вставка**:
   - Создание ноды по `1`, `2`, `3`, `Enter`.
   - Вставка из буфера (`Ctrl+V`), дублирование/клонирование (`Alt+D`).
3. **Групповое перемещение**:
   - Запись начальных и конечных позиций при перемещении нескольких выделенных нод (`transformMove`).
4. **Иерархия списков (листГруппы)**:
   - Сдвиги по `Tab` / `Shift+Tab`.
   - Привязка/отвязка к родителю через drag-and-drop.
5. **Связи фреймов**:
   - Связывание / разрыв связей между фреймами (`Ge_Path`).
6. **Редактирование текста**:
   - Фиксация изменения `title` после завершения редактирования (blur/Enter).
