# Промт: подпроект «Копирование» (copy/paste нод)

## Контекст

- Клиент: `client/src/features/core/Clipboard.ts` (`core.clipboard`), см. `.tasks/clipboard.md`.
- Формат буфера: `text/plain` (заголовки нод) + `text/html` с `<span data-a-nodes="...">`, JSON `{type:"a-nodes", nodes: INodeDB[]}`.
- Сериализация: `toDB` из `@shared/types/INodeDB`. Типы нод: `VTextEdit`, `VTextEditClone`, `LNode`.

## Цель

Реализовать полноценное копирование/вставку/вырезание нод в a-nodes: выделение → Ctrl+C / Ctrl+X / Ctrl+V, включая поддеревья и связи.
