## Эндпоинты

### 1. Получение списка целевых нод (`GET /nodes/quick-targets`)
Возвращает список всех нод, содержащих маркер `>>` (или кастомный параметр `?q=...`), с их заголовками и LID:

```bash
curl -X GET "http://localhost:2010/nodes/quick-targets" \
  -H "x-api-key: anodes_sec_9f7c2a4e8b1d3f605a9e7c1b4d8a2f5e"
```

Параметры query:
- `q`: маркер поиска (по умолчанию `>>`).
- `pageId`: фильтр по странице (опционально).

Пример ответа:
```json
{
  "success": true,
  "targets": [
    {
      "_id": "673f...",
      "title": "Планы >>",
      "cleanTitle": "Планы",
      "parentLID": 136,
      "pageId": "6a217eec3f6bb77979b18240"
    }
  ]
}
```

### 2. Создание ноды (`POST /nodes/quick-add`)

Поддерживаются как `application/json`, так и `text/plain`.

#### А. JSON с указанием родителя по тексту (`parentTitle`)
Сервер находит родителя по имени, автоматически инициализирует ему `lID` (если ещё не был задан) и вставляет новую ноду в конец его дочернего списка:

```bash
curl -X POST http://localhost:2010/nodes/quick-add \
  -H "x-api-key: anodes_sec_9f7c2a4e8b1d3f605a9e7c1b4d8a2f5e" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Купить молоко",
    "parentTitle": "Планы"
  }'
```

#### Б. Полный JSON с явными параметрами
```bash
curl -X POST http://localhost:2010/nodes/quick-add \
  -H "x-api-key: anodes_sec_9f7c2a4e8b1d3f605a9e7c1b4d8a2f5e" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Текст заметки",
    "parentTitle": "Планы >>",
    "pageId": "6a217eec3f6bb77979b18240",
    "parentLID": 136,
    "tab": 1,
    "index": 22,
    "s": 1001,
    "userId": "..."
  }'
```

##### Поля тела JSON:
- `text` / `title` (строка, **обязательно**): текст создаваемой ноды.
- `parentTitle` (строка, опционально): текст или часть текста родительской ноды (например `"Планы"` или `"Планы >>"`). По нему сервер находит родителя и определяет `parentLID` и `pageId`.
- `parentLID` (число, опционально): прямой LID родителя.
- `pageId` (строка, опционально): ID доски/страницы (или `"root"`).
- `tab` (число, опционально, по умолчанию `1`): вкладка/таб (3 бита).
- `index` (число, опционально): индекс ноды в родителе; если не указан, рассчитывается в конец списка (`maxChildIndex + 1`).
- `s` (число, опционально): собственный LID создаваемой ноды.
- `userId` (строка, опционально): ID пользователя.

#### В. Простой текст (`text/plain`)
Создается нода с дефолтными параметрами:
```bash
curl -X POST http://localhost:2010/nodes/quick-add \
  -H "x-api-key: anodes_sec_9f7c2a4e8b1d3f605a9e7c1b4d8a2f5e" \
  -H "Content-Type: text/plain; charset=utf-8" \
  -d "Текст быстрой заметки"
```

---

## Формула упаковки поля `L`

Поле `L` формируется битовой упаковкой:
- `tab`: 3 бита (`targetTab & 0x7`)
- `index`: 12 бит (`(finalIndex & 0xfff) << 3`)
- `parentLID`: 17 бит (`(targetParentLID & 0x1ffff) << 15`)
- Итог: `((t | (idx << 3) | (pLID << 15)) >>> 0)`

## Формат ответа сервера

Успешный ответ (`201 Created`):
```json
{
  "success": true,
  "node": {
    "_id": "673f...",
    "title": "Текст заметки",
    "type": 1,
    "L": 4456625,
    "parentLID": 136,
    "tab": 1,
    "index": 22,
    "pageId": "6a217eec3f6bb77979b18240"
  }
}
```

Ошибки:
- `401 Unauthorized`: неверный или отсутствующий API-ключ.
- `400 Bad Request`: пустой текст ноды.
- `500 Internal Server Error`: ошибка записи в БД.
