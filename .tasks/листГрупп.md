# Управление листГруппами и фильтрами списка

Термины: см. `GLOSSARY.md` (`!листГруппа`, `!фрейм`). Пути от `client/src/features/` и корня проекта.

## 1. Ключевая концепция

Каждая нода со списком дочерних элементов (`node.list = new TList(this)`) управляет видимостью своего поддерева и фильтрами дочерних задач:
- **Раскрытие списка**: сворачивание/разворачивание всех детей узла.
- **Отложенные задачи**: отображение/скрытие нод с активным `repeatMode` (`mode > 0` или `date != null`).
- **Спрятанные ноды**: отображение/скрытие нод с ручным скрытием `hiddenBD === true`.

## 2. Элементы управления в UI (`VTextEdit.ts`, `vNode.scss`)

Контейнер кнопок управления списком: `.el-list-btns` (отображается только при наличии дочерних нод `list.hasChildren`):
- `.bt.btn-open` (серый треугольник): переключает `list.isListOpen`. Класс `.open` при открытом списке.
- `.bt.btn-repeats` (оранжевые часы): переключает `list.isRepeatsOpen`. Отображается только если `list.hasRepeatChildren()`. Класс `.open` при включенном показе отложенных.
- `.bt.btn-hidden` (синий глаз): переключает `list.isHiddenOpen`. Отображается только если `list.hasHiddenChildren()`. Класс `.open` при включенном показе скрытых.

## 3. Битовая упаковка и сохранение (`shared/types/INodeDB.ts`)

В соответствии с принципом максимальной ёмкости хранения, все статусы упакованы в 32-битное числовое поле **`s`** (`blockS: TPackedData<ILNode>`):

| Параметр | Бит в `s` | Логика бита | Значение по умолчанию |
| :--- | :--- | :--- | :--- |
| `lID` | 0..16 (17 бит) | Идентификатор ноды | `0` |
| `isFrame` | 17 (1 бит) | Флаг режима фрейма | `false` |
| `hiddenBD` | 18 (1 бит) | Флаг скрытости самой ноды | `false` |
| `isListClosed` | 19 (1 бит) | **Инвертирован**: 0 = открыт, 1 = закрыт | `0` (открыт, совместимость со старыми записями) |
| `isRepeatsOpen` | 20 (1 бит) | 0 = скрывать отложенные, 1 = показывать | `0` (`false`) |
| `isHiddenOpen` | 21 (1 бит) | 0 = скрывать спрятанные, 1 = показывать | `0` (`false`) |

Всего занято 22 бита из 31/32.

### Сохранение
Каждый клик по кнопкам фильтров в `VTextEdit.ts` вызывает `this.node.save()`, который через шину событий `EVENTS.node.updated` ставит узел в очередь `ServerPersistence.dirtyNodes` на пакетную отправку (`PUT /nodes/saveNodes`).

## 4. Жизненный цикл и синхронизация видимости

1. **Гидрация / Загрузка страницы** (`NodeManager.ts`):
   - `fromDB(nodeData, node)` распаковывает `s` в `node.list.isListOpen`, `node.list.isRepeatsOpen`, `node.list.isHiddenOpen`.
   - `applyTreeVisibility(parent)` рекурсивно вычисляет `child.hidden`:
     - Если родитель закрыт (`!isListOpen`) или скрыт — ребенок скрывается (`child.hidden = true`).
     - Если ребенок отложенный — отображается только при `list.isRepeatsOpen === true`.
     - Если ребенок скрыт (`hiddenBD`) — отображается только при `list.isHiddenOpen === true`.
2. **Интерактивное переключение** (`VTextEdit.ts`):
   - Методы: `toggleListOpen()`, `toggleRepeatsOpen()`, `toggleHiddenOpen()`.
   - Рекурсивно переключают `child.hidden`, вызывают `child.vNode?.show()` / `child.vNode?.hide()`.
   - Обновляют геометрию холста: `mainParent.list.setPositionForChildren()`, перерисовывают связи `mainParent.vNode?.renderSVG()`.
   - Обновляют иконки кнопок через `refreshListBtns()` и сохраняют состояние: `this.node.save()`.

## 5. Связанные классы и файлы

- **Модель и логика**:
  - `client/src/features/nodes/LNode/TList.ts` — состояние списка (`isListOpen`, `isRepeatsOpen`, `isHiddenOpen`), предикаты `hasRepeatChildren()`, `hasHiddenChildren()`.
  - `client/src/features/nodes/LNode/LNode.ts` — владение `list`, методы `hide()`, `show()`, `save()`.
  - `client/src/features/nodes/LNode/TRepeatMode.ts` — логика отложенных задач (`mode`, `date`, `setDelay`).
- **Представление и стили**:
  - `client/src/features/nodes/VNode/VTextEdit.ts` — рендер кнопок `.el-list-btns`, методы переключения и вызов сохранения.
  - `client/src/features/nodes/VNode/vNode.scss` — стили кнопок `.el-list-btns`, `.btn-open`, `.btn-repeats`, `.btn-hidden`.
- **Сериализация и менеджеры**:
  - `shared/types/ILNode.ts` — контракт `ITList`.
  - `shared/types/INodeDB.ts` — битовая маска `blockS` и сериализация `toDB` / `fromDB`.
  - `client/src/features/nodes/NodeManager.ts` — инициализация видимости `applyTreeVisibility()`.
  - `ARCHITECTURE.md` — раздел 3 (стандарты упаковки).
