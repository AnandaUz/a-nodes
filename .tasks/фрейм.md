# Инструкция: режим «Фрейм» и листГруппы

Термины: см. `GLOSSARY.md` (`!фрейм`, `!листГруппа`, `!подфрейм`, `!клон`). Пути от `client/src/features/`.

## Ключевое

- Фрейм = `LNode_TextEdit` с `frame.isFrame === true` (`nodes/LNode/TFrame.ts`).
- **листГруппа во фрейме** — дерево нод (`node.list`), где `list.mainParent` — фрейм. Каждая такая нода получает класс `.in-frame` (`TFrame.initBtns()`).
- Нода во фрейме проверяется через `frame.isInFrame`; её фрейм — `frame.frameNode` (= `list.mainParent`).

## Кнопки включения (power btns)

- Контейнер: `.el-frame-power-btns .sub`, кнопка на каждый дочерний фрейм: `.btn-<frameLID>`.
- Создание: `TFrame.addPowerBtns()` → `vNode.addFramePowerBtn(onOn, onOff, chFrame.lID)` для каждого элемента `frameNode.frame.children`.
- **ON**: `chFrame.frame.addCloneOfNode(node)` → создаётся `LNode_TEClone` (`NodeManager.create_TextEditCloneNode`), `list.setParent(дочернийФрейм, 0)`, пересчёт позиций `setPositionForChildren`.
- **OFF**: `node.clones.removeAllClones()` + `vNode.setRating(-1, chFrame.lID)`.
- Состояние (`.active` = клон существует в этом фрейме): `TFrame.setBtnsState()` — вызывается у родительского фрейма после гидрации/линковки; сброс — `turnOff_PowerBtn(subFrameLID)`.
- Удаление клона выключает кнопку родителя; удаление главной ноды удаляет все клоны.
- Удаление кнопки при разрыве связи: `vNode.removeFramePowerBtnFor(lid)` (`unlinkFromParent`).
- Кнопки добавляются/обновляются при: `+` (`addFrame` → `initBtns`), ручной линковке (`linkToParent` → `initBtns` + `setBtnsState`).
- UI: `nodes/VNode/VTextEdit.ts` (`turnOn_frameMode`, `addFramePowerBtn`), стили `nodes/VNode/vNode.scss` (`.in-frame`, `.el-frame-power-btns`, `.el-frame-btn`).

## Связи

- Модель: `frame.parents: Set<{node, path}>`, `frame.children: Set<LNode_TextEdit>`, DB-поле `f` = `parentsLID` (`pack()`).
- Линия связи — `desk/DeskSVG/Ge_Path.ts` (bezier от правого края родителя к левому краю ребёнка, `redrawPaths()` на обоих концах при перемещении).
- **Авто-создание**: кнопка `.el-frame-btn .btn.ico-plus` → `TFrame.addFrame()`: копия через `NodeManager.copyNode` справа от родителя + `Ge_Path`.
- **Ручная связь**: drag из `.el-frame-link` (`desk/FrameLinkDrag.ts`) на родительский фрейм → `TFrame.linkToParent()`.
- Ограничения `canLinkTo()`: не себя, цель обязана быть фреймом, без дублей, без циклов (`hasDescendant`). Много родителей/детей разрешено.
- **Разрыв**: клик по `Ge_Path` (выделение, `core.desk.selectPath`) + `X`/`Delete` → `unlinkFromParent()` (клоны не удаляются, кнопки убираются).
- Гидрация: `TFrame.init()` восстанавливает связи по `parentsLID`, создаёт пути, `redrawPaths()`.
- Если `lID` отсутствует — выдаётся `getMaxLID() + 1` и сохраняется.

## Чек-лист при правках

1. Новая связь/разрыв → обновить `parentsLID`, `save()`, `redrawPaths()`.
2. Изменение детей фрейма → `initBtns()` + `setBtnsState()`.
3. Клонам не создавать собственные кнопки на «чужие» фреймы без проверки `frameNode.frame.children`.
