## Технические данные и архитектурный маппинг

### Поля базы данных (`shared/types/INodeDB.ts`, `server/src/models/Node.ts`)
- `i?: boolean` — фрейм режима "Входящие" (`isFrameIn`).
- `o?: boolean` — фрейм режима "Исходящие" (`isFrameOut`).
- Не сжимаются в битовые маски, хранятся прямыми булевыми полями в MongoDB и DTO.

### Логика узла и фрейма (`ILNode.ts`, `TFrame.ts`, `LNode_TextEdit.ts`)
- `IFrame`:
  - `isFrame: boolean`
  - `isFrameIn?: boolean`
  - `isFrameOut?: boolean`
- `TFrame`:
  - Методы `setIoMode(mode: 'in' | 'normal' | 'out')`
  - При установке `'in'` — поиск по `core.nodeManager.nodes` фрейма с `isFrameIn === true` и сброс его в `normal`.
  - При установке `'out'` — поиск по `core.nodeManager.nodes` фрейма с `isFrameOut === true` и сброс его в `normal`.
  - Вызовы `vNode.body.classList.toggle('frame-in', this.isFrameIn)` и `classList.toggle('frame-out', this.isFrameOut)`.

### Серверные эндпоинты (`server/src/`)
- Эндпоинт: `POST /api/nodes/move-to-page-in`
- Headers: `Authorization: Bearer <token>`
- Body: `{ nodeIds: string[], targetPageId: string }`
- Ответ: `{ success: true, inFrameId: string, movedCount: number }`
- Метод `getNodesAndPageByNodeId(nodeId, userId, since)`:
  - Находит дочерние `Node.find({ pageId: { $in: pageIdsOnDesk }, o: true })`.
  - Догружает узлы списков этих OUT-фреймов для отображения на внешней странице.
